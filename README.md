# DNF 私服工具箱（背包 / PVF / GM）

## 介绍

- DNF 私服工具箱：PVF 解析/编辑，以及数据库侧的 角色 / 背包 / 邮件 / 宠物 / 时装 / 任务 / GM / 封停 / 角色表 / 数据库 等页签。
- 本仓库是 [Zageku/DNF_pvf_python](https://github.com/Zageku/DNF_pvf_python) 的 fork，本项目地址：[a87150/DNF_pvf_python](https://github.com/a87150/DNF_pvf_python)。
- 源码运行需要 Windows + Python 3.14。
- 依赖、目录结构、技术细节与踩坑记录见 [技术说明.md](技术说明.md)。

## 功能

页签顺序：查询 / 背包 / 邮件 / 宠物 / 时装 / 任务 / GM / 封停 / 角色表 / 其它 / 数据库 / 关于。窗口底部是全局「事件日志」，所有操作与报错都写在这里。

主窗口顶部一排是数据库连接：数据库IP（下拉记住用过的 IP，选中会自动回填端口 / 用户名 / 密码）、端口、用户名、密码、「连接数据库」。连接成功会依次加载在线角色、活动列表、封停列表、可备份的数据库列表和数据库用户列表，按钮随后变成「重新连接」。

### 查询（角色列表）

- 账户查询：填账号名或账号 UID → 点「查询/加载所有」，列出该账号下全部角色；输入框留空则加载全服所有角色。
- 角色查询：填角色名 → 点「查询/加载在线」，自动兼容简/繁写法；留空则只列当前在线角色。
- 角色列表 5 列：角色ID / 角色名 / 等级 / 职业 / UID；已删除角色整行灰底。点行即选中该角色。
- 角色显示及编码：连接器下拉 + SQL 编码下拉（手动指定写库编码，选中后不再自动切换）。
- PVF数据：PVF缓存下拉（选已解析过的 PVF 缓存）、PVF编码下拉（big5 / gbk / utf-8，物品名乱码就换一个重载）、「读取PVF文件」选本机 Script.pvf（服务器上通常在 /home/neople/game/Script.pvf，先下载到本机）。没有 PVF 时可用自带的 CSV 物品表。
- 角色列表底部按钮：刷新背包、道具搜索、装备搜索（后两个直接打开 PVF 编辑器的「道具」/「装备」页签）。

### 背包

5 个子页签：物品栏 / 穿戴栏 / 宠物栏 / 仓库 / 账号金库。每页一个「当前物品列表」，列是 空槽 / 物品名 / 数量 / 物品ID / 稀有度。

- 显示空槽位：切换是否列出空格子。
- 槽位扩充：改物品栏槽位数，提交后按容量校验物品位置。
- 清空物品：按确认框删掉本页全部物品；导出字段：把本页数据存成二进制字段文件（扩展名就是该栏字段名，如 .inventory / .equipslot / .creature / .cargo / .account_cargo）；导入字段：从这类文件覆盖本页。
- 物品信息编辑（选中物品后填充）：封装、ID、数量、耐久、封装次数、启用种类字段/种类、增幅（异次元属性 + 数值）、强化、锻造、异界、宝珠、魔法封印（可选第四词条）。
- 按钮：生成字节（按编辑框内容生成物品字节）、导入字节（把一段字节解析回编辑框，用于复制物品）、删除（标记该槽删除）、重置（放弃当前改动）、提交修改（确认后写回数据库并重新加载该角色）。
- 物品列表右键菜单：复制 / 复制为代码 / 粘贴代码 / 复制全部 / 标记为删除 / 标记为封装 / 取消封装。

### 邮件

- 「发送邮件」面板：物品名或 ID（输入后自动带出物品信息）、封装、数量、耐久、增幅、强化、锻造、金币，以及 发件人、邮件内容（都带历史下拉）。
- 六个按钮决定收件人：发送到当前角色（当前在「查询」页选中的角色）、发送到全服角色、发送到在线角色、发送到VIP账号（每个 VIP 账号发到其首个角色）、发送到VIP角色（VIP 账号下所有角色）、清空全服邮件。发送前都会弹确认；物品 ID 与金币都为 0 时只发文本邮件。
- 左侧「当前物品列表」是本角色收到的邮件（物品名 / 物品ID / 发件人 / 数量 / 类型），「删除选中」删除选中的邮件。

### 宠物

- 当前物品列表：宠物名 / 物品ID / 昵称；「删除选中」删除选中的宠物（写库后重新加载角色）。

### 时装

- 当前物品列表：装扮名称 / 物品ID / 潜能；「设置潜能」给选中的时装设置潜能值，「删除选中」删除选中的时装。

### 任务

- 当前任务列表：任务ID / 任务名 / 任务状态；选中后「任务信息」显示任务名、ID、状态，并展示该任务的 PVF 文本。
- 按钮：放弃选中任务、放弃所有任务、标记状态为完成（需要交物品的任务请自行补发物品邮件）、保存状态（把改过的任务状态写回角色）。

### GM

- 充值：点券 / 代币 / SP / QP / TP，填数额后「充值」，旁边「清零」把当前类型归零；上方实时显示各项当前值。
- PVP：段位、胜场、胜点，「提交」写回。
- 其他功能：解除建号限制（含限制交易、封号等异常状态）、取消装备等级限制、开启左右槽、重置副本次数（祭坛与异界）、开启全图全难度、设置副职业满级。
- 角色信息：角色名 / 等级 / 职业 / 成长类型 / 觉醒标识 / VIP账户 / 回归玩家，「提交修改」；勾「封停账号」封禁该账号。
- 金币复活币：背包 / 金库 / 复活币三行，各自「提交修改」。
- 在线泡点（普通泡点 + 账号泡点）：启用泡点、分钟间隔、发放数额、有效时间；账号泡点另有账号列表（添加账号 / 移除选中、对假人发放泡点开关）与「保存泡点」。
- 活动管理：刷新活动、删除活动，以及用活动名称 + 参数「添加活动」。

### 封停

- 列表列：账号 / UID / 角色ID / 等级 / 角色名 / 职业 / IP / 类型（禁止登陆、限制交易）。
- 账号ID + 类型 →「封禁」；角色名 + 类型 →「封禁」（重名时会提示先去首页查询再操作）；「解除选中封停」解封选中的账号 / 角色。

### 角色表

- 左栏「角色操作」：账号ID +「查找账号」；列表列 状态 / 角色ID / 角色名 / 等级 / 职业 / UID。状态三档：已删除（delete_flag=1）、隐藏（不在该账号的角色显示缓存里）、空。
- 左栏按钮：删除选中角色 / 恢复选中角色（改 delete_flag）、拷贝选中角色（账号内有角色在线时复制出的角色可能被隐藏）、备份选中角色、读取恢复数据。
- 右栏「角色转移」：账号ID +「查找账号」列出目标账号的角色（角色ID / 角色名 / 等级 / 职业），「转移角色到右侧账号」把左栏选中的角色挪过去。
- 备份写在 charac_bak/，文件名 角色ID-账号ID-角色名.cbak；恢复靠文件名解析角色 ID 与账号 ID，所以别改文件名。

### 其它

- 角色信息 + 金币复活币：与 GM 页同一套面板（角色名、等级、职业、成长类型、觉醒标识、VIP账户、回归玩家、封停账号、各栏「提交修改」）。
- 附加功能：生成一键启动器、PVF缓存管理器、PVF工具、启用拍卖行、保存当前分辨率，以及 自动检查更新 / 高分辨率缩放 / 在线人数更新 三个开关和主题下拉。
- 服务器管理（SSH）：服务器IP / 端口 / 用户名 / 密码，「连接服务器」或「密钥连接」；「启动服务器」（执行 /root/run）、「停止服务器」（/root/stop）、「重启频道」（/root/run1）、「上传PVF」（覆盖 /home/neople/game/Script.pvf）；下方四条自定义指令各自「执行」，内容存在配置里。

### 数据库

- 备份还原 → 数据库备份：远端数据库列表（数据库 / 状态）+「全选」「备份选中数据库」，备份到 sql_bak/<IP>_<日期>/。
- 备份还原 → 数据库还原：「打开文件夹」选备份目录，列出 .sqlbak（数据库 / 状态），「恢复选中数据库」逐个还原；还原前请停服并关闭其它连接。
- 备份还原 → 数据库爆破：「数据库重置」用 sql_bak/初始数据库 里的备份把库清空重来，旁边一排红字提示，慎点。
- 用户管理：数据库用户列表（用户名 / 连接域），「新建用户」「删除用户」，右侧填 用户名 / 主机IP / 密码 后「保存修改」。

### 关于

- 软件名、说明、版权信息，以及「原项目地址」「本项目地址」两条链接（点击用浏览器打开）。

## 使用

1. 环境与安装：Windows + Python 3.14；在仓库根目录执行 `pip install -r requirements.txt`。**PyMySQL 必须 1.0.2**，1.1+ 写汉字会乱码。
2. 配置：把 `config/config.example.json` 复制成 `config/config.json`，填好数据库与服务器信息（该文件不入库，别提交）。
3. 启动：源码 `python main.py`，或直接双击 `dist\DNF背包编辑工具.exe`。
4. 连接数据库：在顶部填 数据库IP / 端口 / 用户名 / 密码 → 点「连接数据库」。预期：按钮变「重新连接」，日志出现「当前在线角色已加载(n)」，查询页两个按钮变为可用，角色/物品缓存开始加载。
5. 载入物品表（PVF）：查询页「PVF数据」里点「读取PVF文件」选本机 Script.pvf（或选已有的 PVF 缓存）；物品名乱码就换 PVF编码 重新读。预期：日志显示加载耗时，物品名能正常显示。
6. 查角色 → 查物品 → 改物品：查询页搜出角色并点选（选中即加载该角色的背包 / 宠物 / 时装 / 邮件 / 任务）→ 在「背包」对应子页签里选物品（右键可复制 / 标记删除 / 封装）→ 改「物品信息编辑」里的字段 → 点「提交修改」。注意：账号最好不在线或正在用其它角色。
7. 邮件发物品：切到「邮件」页，填物品名/ID、数量、增幅/强化/锻造等，选 发件人 与内容 → 按收件人点「发送到当前角色 / 全服角色 / 在线角色 / VIP账号 / VIP角色」，确认后发送。
8. PVF 编辑：点底部「道具搜索」/「装备搜索」或「其它 → PVF工具」打开 PVF 编辑器；「文件」菜单是 打开编辑 / 保存编辑 / 另存编辑 / 导出PVF，右上角「导出PVF」同导出。四个页签 道具 / 装备 / 掉落 / 技能，左侧是 1 个搜索栏 + 1 个结果列表 + 4 个按钮（提交编辑 / 提交邮件 / 修改物品数据 / 以该物品为模板）。
9. 角色备份 / 恢复：在「角色表」页选中角色 →「备份选中角色」（写到 charac_bak/角色ID-账号ID-角色名.cbak）；恢复时点「读取恢复数据」选该文件。
10. 生成一键启动器：**先启动游戏**，再到「其它 → 附加功能 → 生成一键启动器」，选择保存位置（建议 DNF.exe 同级目录）；程序读出游戏进程的 exe 与参数拼成 bat，再用 b2e.exe 压成 exe。若提示未找到 DNF 进程，说明游戏没开；若提示读不到 exe 路径，请以管理员身份运行本工具。

**写库前先备份数据库**；中文角色名 / 邮件走 latin1 + bytes 那条链路，别乱升 PyMySQL。

## 修改了什么

- 升级到 Python 3.14 并调整依赖。
- 精简：删死文件 / 无用资源 / 无用依赖，exe 31.27 MiB。
- py3.14 线程模型整改：控件操作一律回主线程，主线程泵不会因异常停止、不会永久挂起。
- PVF 编辑器左侧合并成「1 个搜索栏 + 1 个结果列表 + 4 个按钮（提交编辑 / 提交邮件 / 修改物品数据 / 以该物品为模板）」。
- 新增「角色表」页（状态 / 角色ID / 角色名 / 等级 / 职业 / UID；删除、恢复、拷贝、备份选中角色，读取恢复数据；右栏账号 ID 查找 + 转移角色到右侧账号）；备份文件 `.cbak` 与原版格式一致：zlib + pickle(PROTO3)、16 个裸表名行元组。
- 汉字写库编码修复：PyMySQL 锁 1.0.2 + latin1/bytes 路径。
- 修复打包版连接流程三个根因：print2title 归属、eventList.json 编码导致连接线程死、PyMySQL 在 frozen 进程 getpass 失败导致启动即退。
- 移除 pyqrcode / pypng 依赖与若干无用配置键。
